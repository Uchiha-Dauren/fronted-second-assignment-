TASK 2 — CSS GRID

Page Layout with Grid Areas

A full page frame — header, sidebar, main content, and footer — placed with named grid-template-areas instead of floats or manual positioning.

  • Parent container set as a grid container
  • Rows and columns defined on the grid
  • Header spans the top, footer spans the bottom
  • Sidebar on the left, main content on the right
grid-area: head

Site Header

grid-area: side

Sidebar

Navigation, filters, or supporting links live here.

grid-area: main

Main Content

The primary reading area. In a real page this is where article or product content would sit, sized by the 1fr track next to a fixed 220px sidebar.

grid-area: foot

Footer

How it's wired

The core rule set behind the frame above:

.layout-demo {
  display: grid;
  grid-template-columns: 220px 1fr;
  grid-template-rows: auto 1fr auto;
  grid-template-areas:
    "head head"
    "side main"
    "foot foot";
}
